# Support and license

Contact **hyunter@flycat.co.kr** for product support. Include Unity/package versions, the relevant scene/content setup, exact steps, Console output and the seed/settings/input needed to reproduce a simulation issue. Use the documentation repository for documentation corrections; do not upload purchased implementation source or private project/account data to a public issue.

The package is distributed under the license supplied with the purchased product, including its Unity Asset Store EULA notice. Apply the license supplied with the purchased package to its implementation. Bundled art/audio/font notices and original license texts remain in the package/sample notices.

Documentation text and diagrams are copyright FlyCat. Read and link the documentation and use the example snippets with the product in your projects. Toolchain packages retain their own licenses.

The site is hosted on GitHub Pages. Send support reproductions to hyunter@flycat.co.kr.

# Installation

1. In Unity 6, open **Window > Package Manager > My Assets** and import **Survivor Roguelite Maker**.
2. Install **Unity UI** (`com.unity.ugui` 2.0.0) and **Input System** (`com.unity.inputsystem` 1.17.0) through Package Manager.
3. Wait for script compilation to finish.
4. Set **Active Input Handling** to **Input System Package (New)** or **Both**. Restart the Editor when prompted.

The package is installed at `Assets/SurvivorsMaker/`. The included demo is at `Assets/SurvivorsMaker/Samples/Demo/`.

Continue with the [five-minute demo](demo.md), or create your game with the [first-game guide](first-game.md). Keep your own content and custom code in a separate folder under `Assets`.

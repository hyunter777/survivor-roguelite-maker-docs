# Samples

The included **Demo** contains characters, weapons, enemies, waves, a boss, progression, art and audio.

| Item | Location |
|---|---|
| Demo folder | `Assets/SurvivorsMaker/Samples/Demo/` |
| Scene | `Scenes/ArenaDemo.unity` |
| Editable content | `Content/Generated/` |
| Authoring source | `Content/Data/` |
| Art, audio and font notices | `Licenses/` |

Arena and Field modes use the same scene. Follow the [five-minute demo](demo.md) to prepare its text resources and play.

Keep your own content in a separate game folder. **Build Demo** regenerates the included demo's generated content.
